# OCF 國際盤纏計劃 2026

OCF「國際盤纏計劃」2026 年度徵選網站。純 HTML/CSS/無框架，Google Form（嵌入 iframe）收資料、自動寫入 Google Sheet。

- `index.html` — 首頁導覽
- `rules.html` — 申請辦法（靜態內容，對應內部 `2026徵選辦法草稿.md`）
- `apply.html` — 報名表單（嵌入 Google Form）
- `recommend.html` — 國際會議推薦表單（嵌入 Google Form）

## 本地預覽

直接在瀏覽器開 `index.html` 即可。

## 部署

GitHub Pages，來源分支 `main` 根目錄。

## 資料來源

- 報名表單：OCF 國際盤纏計劃 2026 報名表單（Google Form，回覆寫入「國際盤纏計劃 2026 報名資料」試算表）
- 推薦表單：OCF 國際會議推薦表單（Google Form，回覆寫入「國際盤纏計劃 2026 會議推薦」試算表）

兩份試算表與表單皆存放於 OCF 內部 Google Drive「2.專案執行／[D]國際盤纏計劃 - Amos」資料夾，非本 repo 管理範圍。
